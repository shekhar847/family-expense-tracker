# 💰 Family Expense Tracker

A full-stack Family Expense Tracker web application that helps users manage daily expenses, track spending, and organize family finances.

## 🚀 Live Demo

- 🌐 Frontend: https://family-expense-tracker-orcin.vercel.app
- ⚙️ Backend: https://expense-tracker-backend-j2h7.onrender.com

## ✨ Features

- 🔐 User Registration & Login
- 👨‍👩‍👧‍👦 Family Member Management
- 💸 Add, Edit & Delete Expenses
- 📊 Dashboard with Analytics
- 📅 Date-wise Expense Filter
- 🏷️ Category & Tag Support
- 🌙 Dark Theme UI
- 📱 Responsive Design

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite

- Backend: Render

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shekhar847/family-expense-tracker.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

Open `frontend/index.html` in your browser.
